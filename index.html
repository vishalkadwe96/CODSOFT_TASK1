Project Overview

Understanding the architecture and methodology behind the genre classification system

🎯

Objective

Build a machine learning model that can automatically classify movies into genres (Drama, Comedy, Action, Horror, Romance) based solely on their plot descriptions using natural language processing techniques.

📊

Dataset

IMDb Genre Classification Dataset with 75+ movie samples. Format: ID ::: TITLE ::: GENRE ::: DESCRIPTION. Features include plot summaries and target genre labels.

⚡

Tech Stack

Python, Pandas, Scikit-learn, TF-IDF Vectorization, NLTK for text preprocessing, Matplotlib & Seaborn for visualization. Optimized for low-end hardware.

🧠

Algorithms

Three powerful classifiers were implemented and compared: Multinomial Naive Bayes, Logistic Regression, and Support Vector Machine (SVM) with linear kernel.

🔧

Preprocessing

Text cleaning includes lowercasing, punctuation removal, stopword elimination, and TF-IDF feature extraction with unigrams and bigrams up to 2000 features.

📈

Evaluation

Models evaluated using Accuracy, F1-Macro, and F1-Weighted scores with stratified train-test split and confusion matrix analysis for comprehensive assessment.
